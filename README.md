# 💫 About Me

🔬 Software engineer researching LLM evaluation and empirical software engineering — I study cases where AI systems look reliable on standard metrics but fail in specific, measurable ways those metrics don't capture.

📄 First author on two peer-reviewed publications: evaluating LLM-generated user stories against human baselines (NLP4RE'26 @ REFSQ 2026), and benchmarking LLMs against traditional ML for clinical prediction (IEEE QPAIN 2025).

💼 Currently a Software Engineer I at Synesis IT PLC, building backend services for large-scale public-sector systems.

🧪 Ongoing research on cross-lingual hallucination in open-weight LLMs (English ↔ Bangla).

🌱 Contributor to [tinygrad](https://github.com/tinygrad/tinygrad).

🎓 BSc in Software Engineering, Islamic University of Technology (IUT), Bangladesh.
